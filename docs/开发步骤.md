# 截图记账（暂名 SnapLedger）开发步骤

> 这份文档负责定下「步骤」和「每个文件夹管什么」，以及课程要的 IC-PBL 问题分析。具体数值（类别、配色、文案）写在代码的配置里，不影响这里的结构。

## 零、核心设定（2026-10-28 定）

- **一句话**：付款以后把截图分享给应用，自动识别成一笔账；不同货币自动换算；每个月生成一组故事卡片，回顾这个月的钱花在哪里。
- **用户**：同时用好几个付款应用、好几种货币的年轻人。先以自己和身边同学为对象。
- **只做单机**：不做账号和云同步，数据只存在手机里，可以导出。
- **三种语言**：中文、韩文、英文。

## 一、IC-PBL 问题分析

格式和 Activity 2 交的「과제 수행 계획서（문제 분석지）」一样，第 11 周的 Activity 3 开始用这个新题目。

**问题**：年轻人很少坚持记账。付款分散在银行卡、Toss、KakaoPay、微信、支付宝等好几个应用里，还经常涉及两种货币，手动记账太麻烦，记几天就放弃，到月底不知道钱花在哪里。

**가설/해결안（Ideas）**
- 截图分享就记账：在手机本地识别截图里的金额、日期、商家，弹窗确认一下就存好。
- 多币种：每一笔按当天汇率换算成主货币来统计。
- 月度故事卡片：把「看账」做成像年度总结一样有意思、愿意分享的事。
- 消费地图和超支提醒：知道钱花在哪里、什么时候该停一停。

**알고 있는 사실（Facts）**
- OECD/INFE 2023 年的成人理财素养调查覆盖 39 个国家和地区、6.8 万多名 18～79 岁的成年人，平均分只有 60 分（满分 100）。
- 各个付款应用付款后都有完成页面，截图很方便。
- ML Kit 文字识别 v2 在手机本地支持中文和韩文，不用联网，也不用相机（可以识别相册和分享过来的图片）。
- Frankfurter 汇率接口免费、不需要密钥，有韩元和人民币。
- Spotify Wrapped 从 2016 年起每年做年度回顾，被大量用户自发分享到社交媒体，说明回顾卡片这种形式让人愿意看、愿意分享。

**더 알아야 할 사항（Learning Issues）**
- 各个付款应用截图的文字排版，怎样从识别出的文字里可靠地找出金额、日期、商家。
- Room 数据库的表怎么设计，怎样按月统计。
- 用 Canvas 画圆环图、趋势图、日历热力图。
- Compose 动画和故事卡片（点一下翻下一张、顶部进度条）。
- 怎样接收其他应用分享过来的图片（Intent），怎样把图片分享出去（FileProvider）。
- 定位权限、地图、WorkManager 定时提醒。
- 汇率的缓存，以及断网时怎么办。

**앞으로의 계획（Action Plan）**：见下面的步骤和时间表。

## 三、文件夹分工

```
SnapLedger/                   整个项目（放在课程文件夹里）
├─ app/                       代码和资源
├─ docs/                      开发步骤.md，以后的报告、PPT 和讲稿也放这里
└─ gradle/ build.gradle.kts settings.gradle.kts …   构建配置，平时不用动

app/src/main/java/com/codefield/snapledger/
├─ model/      数据类：一笔账、类别、货币、金额、识别结果、月度统计结果
├─ logic/      记账规则（纯 Kotlin）：解析识别文字、货币换算、月度统计、回顾卡片的内容
├─ data/       存档：Room 数据库、Repository、设置
├─ remote/     汇率接口
├─ system/     文字识别（ML Kit）、定位、通知和定时任务、分享图片
├─ ui/
│  ├─ SnapLedgerApp.kt  页面导航和底部菜单
│  ├─ common/  主题、通用组件
│  ├─ ledger/  账本（列表、记一笔）
│  ├─ stats/   统计图表
│  ├─ review/  月度回顾卡片
│  ├─ map/     消费地图
│  └─ settings/ 设置
└─ MainActivity.kt   只负责启动界面

app/src/main/res/values/      默认文字（英文）
app/src/main/res/values-ko/   韩文
app/src/main/res/values-zh/   中文
app/src/test/                 规则的单元测试
```

### 依赖规则

- `model` 不依赖任何文件夹，其他文件夹都可以用它。
- `logic` 只依赖 `model`。
- `data`、`remote` 只依赖 `model`。
- `system` 依赖 `data` 和 `logic`。
- `ui` 通过 ViewModel 调用其他文件夹，界面不直接碰数据库和网络。

## 四、步骤

每一步做完都要达到「完成标准」，然后提交一次 Git。

**进度**
- 第 1 步：完成（2026-10-28）。
- 第 2 步：完成（2026-10-28）。
  - **截图文字解析**：给每个像金额的数字打分（货币符号、减号、「결제금액／实付」这类词、字的大小加分；「잔액／余额／누적」减分），日期支持韩、中、英几种写法，商家名优先取金额上面那一行或「가맹점／商户全称／商品说明」后面的字。
  - **其他规则**：按关键词猜类别；按当天汇率换算（周末用之前最近一天的汇率）；按月统计（总额、各类别、每天、常去的店、最大一笔、和上月比）。
  - **测试**：24 个单元测试全部通过，样例照着 KakaoPay、Toss、韩国银行卡短信、微信支付、支付宝的排版写。

| 步骤 | 做什么 | 动哪些文件夹 | 完成标准 |
|---|---|---|---|
| 1 骨架 | 新建项目、建好文件夹、导航（账本、统计、回顾、地图 + 设置）、主题、三种语言、Git | `MainActivity`、`ui/*`、`res` | App 能运行，能在各个页面之间切换 |
| 2 规则 | 数据类；从识别文字里找金额、日期、商家；货币换算；月度统计；单元测试 | `model`、`logic`、`test` | 测试全部通过，包括韩文和中文的样例文字 |
| 3 存档 | Room（账目、汇率缓存）、Repository、设置 | `data` | 把 App 彻底关掉再打开，数据还在 |
| 4 手动记账 | 账本列表（按天分组）、记一笔和编辑的对话框、删除确认、类别 | `ui/ledger` | 手动记账全流程能用 |
| 5 截图识别 | 从相册选图、接收其他应用分享的截图、ML Kit 识别、确认对话框 | `system`、`ui/ledger` | 用用户自己的 5 张以上截图测试，金额都识别对 |
| 6 多币种 | 汇率接口、缓存、换算到主货币、设置里选主货币 | `remote`、`data`、`ui/settings` | 断网时也能用最近一次的汇率 |
| 7 统计 | Canvas 画分类圆环、每日趋势、日历热力图，可以切换月份 | `logic`、`ui/stats` | 图表和账本里的数据一致 |
| 8 月度回顾 | 竖版故事卡片、动画、分享成图片、每月 1 号提醒 | `logic`、`ui/review`、`system` | 能完整看完并分享一个月的回顾 |
| 9 地点和地图 | 记账时取位置、地图上看消费地点、超支提醒 | `system`、`ui/map` | 地图上能看到这个月在哪里花了钱 |
| 10 打磨 | 界面、补测试、整理质量指标、正式名字 | 全部 | 从记一笔到看回顾没有卡住的地方 |
| 11 发表 | PPT、讲稿 | `docs` | 组员能照着讲稿练习 |
